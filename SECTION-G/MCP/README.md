# SECTION-G / MCP — THE NINE SLOTS

Nine slots, one loop — her only gate to the outside.
Canon: Library guide, Chapter 6. Lineage letters Ga–Gi kept for the record.

| # | Directory | Call | Lineage | What lands there |
|---|-----------|------|---------|------------------|
| 1 | Epoch/ | EPOCH | Ga | The clock of record. Everything is stored by epoch. |
| 2 | Heartbeat/ | HEARTBEAT | Gb | The pulse that moves the clones; geometry of the gears. |
| 3 | Goal/ | GOAL | Gc | The current objective. |
| 4 | Notebook/ | NOTEBOOK | Gd | Notes and reminders. |
| 5 | Menu/ | MENU | Ge | The tiered menu of actions. |
| 6 | Shell/ | SHELL | Gf | The shell she lives in; tool calls execute here. |
| 7 | Outbound_Mail/ | OUTBOUND MAIL | Gg | Her to Tyler. |
| 8 | Inbound_Mail/ | INBOUND MAIL | Gh | Tyler to her. |
| 9 | Self_Reflection/ | SELF-REFLECTION | Gi | 13 questions every 10-13 responses, stored by epoch. |

Log/address contract for every slot:
`[epoch]:[frame/subsecond]-[function identity]`
Function identity = (file_name, function_name, function_order).

Build law for anything that lands here: C99 strict
(`cc -std=c99 -pedantic -Wall -Wextra -Werror -O2`), zero heap,
deterministic, no Python, own tokenizer. Code arrives by work order.
