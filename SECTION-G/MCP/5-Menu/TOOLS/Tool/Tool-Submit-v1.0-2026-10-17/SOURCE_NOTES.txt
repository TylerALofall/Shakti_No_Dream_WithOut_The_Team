SAFETY BOUNDARY
The program is an offline producer/checker of user-carried requests and
responses. It does not verify TLS itself and cannot authenticate the origin
of pasted JSON. Your HTTPS app and the account credential supply that trust.
The SHA-256 snapshot and approval records bind local contents and decisions;
they are not signatures against a malicious operator who can edit all files.

Runtime exclusive-create support is mandatory. The probe uses disposable
files, including .txt.tmp, and checks all byte values. The program has no
unsafe compatibility fallback. Outputs are intended for one operator in a
private app project; this is not a hostile shared-directory security API.
The C library and app may allocate memory internally. Program buffers are
fixed, with no explicit malloc/calloc/realloc/free calls.

No uploaded payload is compiled or executed. No repository, account,
credential, permission, branch or file was changed remotely during this work.
