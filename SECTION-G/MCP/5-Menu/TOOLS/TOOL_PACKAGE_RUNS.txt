All successful builds used:

All 17 directory seals and every README payload hash independently matched
using the host SHA-256 utility. The saved assembler rebuilt cleanly and its
new executable matched the executable used for the full Menu package run.
The packaged assembler source also matches that saved source byte for byte.
Repeat packaging preserves identical packages and the ledger. Repository
change reporting remains with the existing hash tools; it does not gate
packaging another tool. No submitted tool is built or run by the assembler.

LIMITS
These are actual example runs on isolated Linux copies, not proof of every
possible input or an iOS validation. Call Scan currently uses Linux
renameat2; its existing source needs a native iOS publication path before
an iOS build can be claimed. The other successful builds use the native C
library and, where needed, native POSIX file/directory APIs. No downloaded
dependency was installed for these runs. The missing ZIP header was not
invented or replaced with an external library.

No explicit malloc/calloc/realloc/free calls were found in the packaged C
sources. The assembler uses fixed buffers; native library internals may
allocate, so whole-process zero-heap operation is not established here.
Packaging checks declared file presence and metadata; it does not prove
that an undeclared companion file is unnecessary.

User device and account testing is not part of these program runs. Source
review and source edits remained separate actions. The original frontend
and shell are outside this change. Main is not modified.
